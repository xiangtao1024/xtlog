Features

把散落各处的日志，收拢成一个界面

无论日志在本地文件、远端机器，还是应用自己能改代码，xtlog 都能接进来。单机优先、零外部依赖、数据不出门——让你专注看日志本身，而不是运维一套日志系统。

📥

四种日志来源

HTTP 上报、FILE 文件跟随、CMD 命令流、Rust 客户端远程采集，本地与远端一体覆盖。

🧩

不挑日志格式

Java / nginx / syslog / 任意文本通吃。内置多格式时间戳识别，能正确切分条目、提取级别与时间。

⚡

实时跟随

SSE 长连接推送，块状控制台（时间/级别/logger/IP + 多行堆栈），支持暂停、清屏、全屏。

🔍

历史检索

时间窗 + 级别 + 关键字 + 应用多维过滤，FTS 全文索引，双击看详情含 traceId 与来源 IP。

🌐

来源 IP 追踪

每条日志记录来源机器，微服务多实例下能分清是哪台机器打的，多网卡自动优选真实 IP。

🗂️

分类与应用管理

树形分类按业务线/环境组织应用；应用可启用/停用，停用即拒收，删除连带清日志不留垃圾。

💾

零外部依赖

自带 SQLite 驱动，默认一个文件库（WAL）。要 MySQL / PostgreSQL？丢个驱动 jar 进 drivers/ 即可。

📅

按月分表

日志自动落入 xt_log_entry_YYYYMM，历史查询自动 UNION，无需手工维护归档。

🔔

告警规则引擎

按级别/关键词/正则/速率定义触发条件，配评估窗口与静默，命中即推 Webhook（钉钉/飞书/企微/Slack）。

Ingestion

四路采集，本地远端都接得住

不管日志在别的机器、在本机文件，还是应用自己能改代码，总有一种接法适合你。

HTTP

应用主动上报

JSON 单条/批量，跨语言通用。微服务各实例自带 srcIp，轻松分清来源机器。

FILE

文件增量跟随

按字节偏移跟随日志文件，支持轮转与多行堆栈合并，落在本机服务上。

CMD

命令流采集

常驻执行一条 shell，把输出当日志流，如 journalctl -u game -f -o short-iso。

Rust

xtlog-client

独立二进制，装在别的机器上采集后推送过来，单文件零运行时依赖。

Alerting

别再盯着屏幕，让日志自己喊你

内置规则引擎每 30 秒扫描一次，命中阈值即生成事件并推送 Webhook，静默期内自动合并避免刷屏，恢复后自动标记。

1
定义规则级别 / 关键词 / 正则 / 速率，配评估窗口、阈值、静默时长、作用应用
2
引擎每 30s 扫描在评估窗口内对日志月表聚合匹配，命中数 ≥ 阈值即触发
3
触发 + 推送生成事件并发 Webhook（钉钉 / 飞书 / 企业微信 / Slack 机器人）
4
合并 / 恢复 / 认领静默期内合并到同一事件；命中降到阈值一半下自动恢复；可手动认领

规则类型

LEVEL · ERROR,WARN KEYWORD · 任意文本 REGEX · \bTimeoutException\b RATE · N 次/分钟

命中即 POST JSON，字段含 event_id / rule_name / app_name / level / hit_count / summary / sample_message，可直接转发给任意入站机器人。

Who it's for

适合这样的你

把日志集中起来看，本不该需要一套庞大的基础设施。如果你符合下面几点，xtlog 会非常顺手。

🖥️

日志散在 1～5 台机器

没有专职运维，也不想为看日志专门搭集群，一个 jar 就够了。

🔒

数据要留在自己机器

合规、成本或网络不稳，不想把日志推到外部服务，全部落在本机 SQLite。

🪶

机器资源有限

老的 1C2G VPS、树莓派、嵌入式 Linux 也能跑，512M 内存可起。

🧷

想给多种日志一个入口

Nginx / journalctl / Spring Boot / Flask / Express 统一查看 + 告警。

🚀

想要开箱即用

不想调 Lucene DSL、不想做索引调优，建应用、配路径就能看。

📈

日志量中等

中小团队与个人项目量级，单机 SQLite 按月分表轻松承载。

Quick Start

三步跑起来

从 dist 部署包直接解压即用，或源码构建。默认管理员 admin / admin123，首次登录请改密码。

# 1. 解压部署包（Windows 用 bin\start.bat） unzip xtlog-server-0.0.1.zip && cd xtlog-server-0.0.1 bin/start.sh # 2. 浏览器打开，默认端口 18080 http://localhost:18080 # 3. 应用里新建应用拿到 token，HTTP 上报一条日志 curl -X POST http://localhost:18080/api/logs \ -H "Content-Type: application/json" \ -d '{"token":"<应用token>","level":"ERROR","logger":"com.svc.Gateway","message":"网关超时","srcIp":"10.0.0.21"}'
环境变量说明
XTLOG_DATA_DIR数据目录（默认安装目录下 data/）
XTLOG_HOST_IP手动指定本机 IP，FILE/CMD 采集写入日志的 src_ip
JAVA_OPTSJVM 参数，如 -Xmx1g
